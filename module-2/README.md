# Module-2: スマートコントラクト

## 1. スマートコントラクトに触れる

[`Counter` コントラクト](./contracts/Counter.sol)を開いて、指定された箇所を実装してみましょう。

## 2. 権限・制約を実装する

- [`CounterOwnable` コントラクト](./contracts/CounterOwnable.sol)を開いて、指定された箇所を実装してみましょう。
- オプショナル: [`CounterPausable` コントラクト](./contracts/CounterPausable.sol)を開いて、指定された箇所を実装してみましょう。

## 3. ERC-20規格のトークンを実装する

[`ERC20` コントラクト](./contracts/ERC20.sol)を開いて、指定された箇所を実装してみましょう。

## 🔍 コマンド一覧

| コマンド | 説明                                  |
| -----------: | :---------------------------------------- |
|  `dev` | ローカルネットワークの立ち上げ |
|  `compile` | コントラクトのコンパイル |
|  `deploy:counter` | `Counter` コントラクトのデプロイ |
|  `deploy:counterOwnable` | `CounterOwnable` コントラクトのデプロイ |
|  `deploy:counterPausable` | `CounterPausable` コントラクトのデプロイ |
|  `deploy:erc20` | `ERC20` コントラクトのデプロイ |
|  `run:counter` | `Counter` コントラクトに対するスクリプト実行 |
|  `run:counterOwnable` | `CounterOwnable` コントラクトに対するスクリプト実行 |
|  `run:counterPausable` | `CounterPausable` コントラクトに対するスクリプト実行 |
|  `run:erc20` | `ERC20` コントラクトに対するスクリプト実行 |
